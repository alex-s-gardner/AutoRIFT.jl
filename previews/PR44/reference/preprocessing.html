Preprocessing ​

An ImagePair holds the two images and their validity masks. preprocess applies a preprocessing method to an image or a pair. The filters below are the same operations called directly, for inspecting what a method does to an image.

AutoRIFT.ImagePair Type
julia
ImagePair{T}

The two images to correlate, with their validity masks.

reference is the earlier acquisition and secondary the later one.

reference_valid and secondary_valid mark pixels carrying real data. Invalid pixels arise from sensor gaps, cloud masks, and the no-data border left by reprojection. They do not contribute to a correlation.

The two images and the two masks have separate type parameters, so a pair may mix containers: a lazy reference with a resident secondary, or a default AutoRIFT.FiniteMask beside a supplied dense mask.

The constructor throws DimensionMismatch unless both images and both masks have the same size.

source
AutoRIFT.FiniteMask Type
julia
AutoRIFT.FiniteMask(parent)

The validity mask "every finite pixel of parent", computed on read rather than stored.

This is the default mask when a caller supplies none. It is lazy so that a blocked run forms no scene-sized array: reading a window of the mask reads only that window of parent.

Materialize with AutoRIFT.resident before reducing over the whole mask or reading it more than once.

IndexStyle is forwarded from parent.

source
AutoRIFT.resident Function
julia
AutoRIFT.resident(mask) -> AbstractMatrix{Bool}

mask backed by storage: itself if it already is, one pass over it if it is computed.

Call this before any whole-array reduction over a mask, and before reading one repeatedly. The windowed filters do both.

Only the lazy masks this package constructs are recognized. A caller supplying a computed AbstractMatrix{Bool} of their own should materialize it first or add a method here.

AutoRIFT.preprocess Function
julia
preprocess(pair::ImagePair, method) -> ImagePair

Apply a pre-correlation filter to both images, returning a new pair with an updated validity mask.

method is a PreprocessMethod or the Symbol naming one. The result is Float32 regardless of input type, since every filter produces signed values.

The validity mask can only shrink: a filter with a w-wide window spreads each invalid pixel over a w-wide neighborhood, because an output computed partly from fill values is not a measurement.

source
julia
preprocess(img, mask, method) -> (filtered, mask)

Filter a single image, returning it with its shrunken validity mask.

The pair form applies this to each image. Filtering per image lets a time series filter each acquisition once, although it is the secondary of one pair and the reference of the next.

source
julia
preprocess(img, mask, method, seed::UInt64) -> (filtered, mask)

preprocess with the seed for the one filter that draws random numbers.

Only WallisGapfill reads seed, which seeds a fresh Random.Xoshiro for each call. Every other method ignores it.

AutoRIFT.replace_nonfinite Function
julia
replace_nonfinite(pair::ImagePair) -> ImagePair

Replace non-finite pixels with zero, leaving the element type alone.

Images reach the correlator in the caller's own type, so Int16 sensor data is correlated as Int16. The correlator widens per element where it must (chips to Float32, sums to Float64).

AutoRIFT.highpass Function
julia
highpass(img, mask, width) -> Matrix{Float32}

Subtract a local mean of side width: the identity minus a box filter. It removes an illumination gradient, and is the only filter the production driver applies inside the correlator.

Invalid pixels are excluded from the local mean rather than counted as zeros, so a no-data border does not bias the mean of the pixels near it. Invalid and non-finite outputs are NaN.

source
AutoRIFT.highpass! Function
julia
highpass!(out, img, mask, width; scratch = nothing) -> out

highpass writing into out, which must have img's shape.

For tiled processing, which reuses out and scratch across blocks. scratch is a second array of the same shape, used only when mask excludes something; passing one makes the call allocation-free in that case too. Its element type must be promote_type(eltype(img), Float32), which is Float32 for every real sensor type and Float64 for a Float64 image.

AutoRIFT.wallis Function
julia
wallis(img, mask, width, min_std = 0.0) -> Matrix{Float32}

Wallis (1976) adaptive contrast filter: subtract the local mean and divide by the local standard deviation over a width-wide window.

Equalizes contrast across the scene, so a shadowed slope and a sunlit one become comparable. In textureless areas the division amplifies noise; min_std floors the divisor to limit that, and 0.0 disables the floor. Invalid pixels, and pixels whose window has no contrast, are NaN.

The local variance is computed in a numerically poor form

The divisor is sqrt(E[x²] - E[x]²) clipped at zero, matching _preprocess_filt_std (autoRIFT.py:47-56). The difference of two nearly equal numbers cancels badly on a bright, low-contrast window. On a 256² scene of mean 130 and standard deviation 25 at width = 5, it differs from an exact Float64 result by a median of 0.54 (up to 5.79), where squaring the deviations about the measured mean differs by a median of 1.5e-6. The clip at zero prevents a negative variance from becoming NaN in the validity mask.

This form is kept for agreement with the production Python. The stable form changes 90% of a filtered scene by a median of 0.113 on a field clamped to ±3, and on LT05_L1GS_001013 it changes the band-reject decision of Destripe. dev/CORRECTNESS.md item 4 records the plan to restore it, and tools/golden/README.md the measurement.

AutoRIFT.wallis_gapfill Function
julia
wallis_gapfill(img, mask, width, std_cutoff; rng) -> (Matrix{Float32}, Matrix{Bool})

wallis, with interior no-data gaps and low-contrast patches replaced by white noise.

For Landsat-7 imagery acquired after the 2003 Scan Line Corrector failure, which has wedge-shaped interior gaps. Masking a gap invalidates every chip that overlaps it. Filling it with noise instead suppresses the correlation peak where a chip is mostly gap, and keeps chips that only touch one.

The noise is standard normal and not rescaled: wallis has already divided by the local standard deviation, so valid pixels have about unit variance.

Each pixel falls in one of three regions:

  • Measured: enough valid neighbors and enough contrast. Normalized as in wallis.

  • Filled: an interior gap, or a patch whose local standard deviation is below std_cutoff, within 30 pixels of valid data. Replaced by noise and marked valid.

  • Excluded: more than 30 pixels from any valid pixel. Set to zero and marked invalid.

std_cutoff is an absolute threshold on the local standard deviation, in the input's units. A low-contrast window is filled, whereas Wallis's min_std clamps the divisor.

Gaps are taken from mask, not from img == 0. A sensor that writes zeros as fill needs a mask that says so.

rng supplies the noise. Throws DimensionMismatch if img and mask differ in axes.

source
AutoRIFT.laplacian Function
julia
laplacian(img, mask, width) -> Matrix{Float32}

Laplacian of the decibel image: ∂²/∂x² + ∂²/∂y² applied to 20 log10(A).

The log is taken first. Radar brightness varies multiplicatively, so a second derivative of raw amplitude scales with local brightness. In decibels that variation is an additive offset, which a second derivative removes.

Second-order kernels of side width are summed across the two axes and applied as one convolution.

source
AutoRIFT.sobel Function
julia
sobel(img, mask, width) -> Matrix{Float32}

Sum of the x and y Sobel derivative kernels of side width, applied as one kernel.

The output is Gx + Gy, with the two derivative kernels added and convolved once. It is not the gradient magnitude sqrt(Gx² + Gy²) or |Gx| + |Gy|, so the response is directional: it partially cancels along one diagonal and reinforces along the other, and it is not an edge strength.

Kernels are the unnormalized separable binomial-difference pair OpenCV's getDerivKernels returns, so at width = 5 the x kernel is [-1,-2,0,2,1] ⊗ [1,4,6,4,1].

source
AutoRIFT.deramp Function
julia
deramp(img::AbstractMatrix{<:Complex}, mask, axis = :both) -> Matrix{ComplexF32}

Remove the linear phase ramp from a complex image. See Deramp.

The ramp is estimated from the image itself, following ISCE2's cuAmpcor (cuDeramp.cu, method 1). For each axis, the conjugate products of adjacent valid pixels are summed and the argument of the sum is the phase gradient per pixel. Summing the products weights each pair by |z_i||z_{i+1}|, so bright pixels dominate, and the argument is taken once after the sum, so no phase unwrapping is needed.

axis is :x, :y, or :both. Invalid pixels are excluded from the estimate but are still deramped. The phase is referenced to the first sample.

AutoRIFT.decibel Function
julia
decibel(img, mask) -> (Matrix{Float32}, Matrix{Bool})

Amplitude to decibels, 20 log10(A), with the mask narrowed to the pixels that have one.

The input is amplitude, so the factor is 20 rather than 10. Intended for radar, where brightness varies multiplicatively and the log turns that into an additive offset the windowed filters remove.

A pixel whose amplitude is not positive, or that is masked, has no decibel value. It is written as zero and marked invalid in the returned mask.

source
AutoRIFT.bytescale Function
julia
bytescale(img, mask) -> Matrix{UInt8}

Rescale img to 256 levels by its own mean and standard deviation: ±3σ about the mean maps onto 0:255, and a masked or non-finite pixel becomes zero.

Reproduces the last step the ITS_LIVE production driver applies before correlating (autoRIFT.py:345-379). Three details of the reference's arithmetic change the result:

  • The statistics are the sample standard deviation (n - 1 in the denominator).

  • The multiplier is 256, not 255, so the top of the ±3σ window lands one level past the representable range and is clipped.

  • Values are clipped before rounding, so a value above the window becomes 255.

mask selects the pixels the mean and standard deviation are taken over. Every pixel outside it, and every non-finite pixel, is written as zero.

Per-pixel arithmetic runs in the image's own precision, T = float(eltype(img)). The two sums accumulate in Float64: a Float32 accumulator over a scene-sized array loses the addends. On the 10980² highpass field of the golden Sentinel-2 pair it gives a standard deviation of 278.97 against 296.55 in Float64, which rescales every pixel.

A one-level difference from the reference remains where a value sits on a rounding boundary: the pinned fixtures agree on all but 1 pixel of 49,827, and over the golden Sentinel-2 scene 99.9984% of pixels agree exactly and the rest are within one level.

Throws ArgumentError if fewer than two pixels are valid or the valid pixels have zero standard deviation. Quantizing before correlating costs accuracy (see dev/CORRECTNESS.md).
